About this project

Meta-analyses increasingly confront a challenge that standard methods were not designed to handle: studies that contribute more than one effect size estimate, so that estimates from the same study are statistically dependent. Treating dependent estimates as independent overstates the information in the data and produces standard errors that are too small. This protocol provides a complete, reproducible workflow for conducting a meta-analysis with dependent effect sizes in R.

The protocol proceeds through the full sequence of decisions a researcher faces: cleaning and quality-checking the data, describing the effect size distribution and study weights, choosing the within-study correlation (rho), comparing five estimators of increasing complexity and selecting the correlated-and-hierarchical effects (CHE) model, testing and correcting for publication bias with PET-PEESE together with robustness checks based on alternative weighting and step-function selection models, estimating a full meta-regression, and deriving best-practice effect size predictions. It then extends the entire analysis using Robust Bayesian Meta-Analysis (RoBMA), which corrects for publication bias by averaging over competing models of the selection process, and concludes by comparing what the two approaches imply about the same literature.

Every step is illustrated with real data: the 957 effect sizes from 83 studies analyzed in Xue, Reed, and van Aert (2025, Journal of Economic Surveys), a meta-analysis of the effect of social capital on economic growth. All data, code, and pre-computed results are included in the repository, so the document can be rendered and every table and figure inspected without re-running the long Bayesian estimations.

How to reproduce the analysis

  1. Download the ZIP file above and unzip it to a folder on your computer.
  2. Install R, RStudio, and the required packages listed in the repository README (one install.packages() call plus metaselection from GitHub).
  3. Replace the setwd() path at the top of each script (and in the qmd's setup chunk) with your own folder. RStudio's Find in Files does this in one pass; details in the README.
  4. Open Protocol_Combined.qmd in RStudio and click Render to reproduce the full document from the included outputs, or run each section's source() chunk to regenerate every result from the raw data.

Approximate run times for every script, and guidance on which long-running steps can be skipped by using the included fitted models, are given in the repository README.
